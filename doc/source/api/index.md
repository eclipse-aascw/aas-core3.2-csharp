# aas-core 3.2 C# API

The API of the SDK is split into six different units:

| Namespace                                                                | Description                                        |
|--------------------------------------------------------------------------|----------------------------------------------------|
| [AasCore.Aas3_2](AasCore.Aas3_2.yml)                           | Create the model programmatically                  |
| [AasCore.Aas3_2.Visitation](AasCore.Aas3_2.Visitation.yml)     | Iterate over and transform the model               |
| [AasCore.Aas3_2.Constants](AasCore.Aas3_2.Constants.yml)       | Specify constants such as constant sets of strings |
| [AasCore.Aas3_2.Verification](AasCore.Aas3_2.Verification.yml) | Verify that the model fulfills the constraints     |
| [AasCore.Aas3_2.Jsonization](AasCore.Aas3_2.Jsonization.yml)   | De/serialize from/to JSON                          |
| [AasCore.Aas3_2.Xmlization](AasCore.Aas3_2.Xmlization.yml)     | De/serialize from/to XML                           |
| [AasCore.Aas3_2.Enhancing](AasCore.Aas3_2.Enhancing.yml)       | Wrap and enhance instances of the model            |

Please refer to [Getting Started](../getting_started/intro.md) for a brief introduction on how to use the API.
