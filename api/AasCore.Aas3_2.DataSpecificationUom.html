    Name of the classification system used for the definition of units and quantities.

    Declaration
    public string? ClassificationSystem { get; set; }
    Property Value
    Type Description
    string
    Remarks

    The most prominent classification systems should be denoted as follows: "ECLASS", "IEC CDD", "UNECE Rec 20", "UNECE Rec 21", "BIPM", "OPC UA", "SAMM".

    This list is not exclusive.
