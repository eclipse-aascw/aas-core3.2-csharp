    reader is expected to be positioned either at the first <member> start element, or already at the enclosing element's own end element if there are no members at all.     SerializeValueTo(JsonNode?, XmlWriter)

    Serialize that, embedded within a larger XML document which is already being written through writer.

    Declaration
    public static void SerializeValueTo(JsonNode? that, XmlWriter writer)
    Parameters
    Type Name Description
    JsonNode that
    XmlWriter writer
    Remarks

    This writes exactly one discriminator element (<nil>, <boolean>, <double>, <string>, <array> or <struct>). that must be JSON-able (recursively a null, a boolean, a number, a string, an array or an object with string keys), or a AasCore.Aas3_2.SerializationFailure is thrown, carrying the path to the culprit within that. The enclosing serializer converts it -- To(IClass, XmlWriter) does, and so does SerializeValue(JsonNode?, XmlWriter) -- so a caller driving this method itself catches SerializationException around the whole document instead.
