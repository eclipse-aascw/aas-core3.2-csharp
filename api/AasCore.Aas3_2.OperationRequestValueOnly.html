    Remarks

    The arguments are given in the ValueOnly serialization, i.e., as a JSON object whose keys are the ID-shorts of the argument values and whose values are the ValueOnly serializations of the argument values. Their shape depends on the concrete submodel elements and can not be pinned down statically, so they are represented as open JSON objects.

    See: https://industrialdigitaltwin.io/aas-specifications/IDTA-01002/v3.2/specification/interfaces-payload.html#operation-request-value-only
