    Enum Content

    Content indicates the kind of serialization of the response or input content.

    Namespace: AasCore.Aas3_2
    Assembly: AasCore.Aas3_2.dll
    Syntax
    public enum Content
    Remarks

    See: https://industrialdigitaltwin.io/aas-specifications/IDTA-01002/v3.2/specification/interfaces-operation-parameters.html#SerializationModifier

    Fields

    Name Description
    Metadata

    Only metadata of an element or child elements is returned; the value is not.
    Normal

    The standard serialization of the model element or child elements is applied.
    Path

    Returns the ID-short of the requested element and a list of ID-short paths to child elements if the requested element is a Submodel, a SubmodelElementCollection, a SubmodelElementList, an AnnotatedRelationshipElement, or an Entity.
    Reference

    Only applicable to Referables. Only the reference to the found element is returned; potential child elements are ignored.
    Value

    Only the raw value of the model element or child elements is returned; it is commonly referred to as ValueOnly-serialization.
